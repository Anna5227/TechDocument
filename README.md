# Angular HelloWorld

Демонстрационный проект на Angular, созданный с помощью Angular CLI версии 15.0.0.
Подойдёт для быстрого старта, изучения основ фреймворка и как шаблон для новых приложений.

## Возможности

- Готовое к работе Angular-приложение
- Автоматическая перезагрузка при изменении исходных файлов
- Генерация компонентов, директив, пайпов, сервисов и других сущностей через Angular CLI
- Сборка production-версии в папку `dist/`
- Юнит-тестирование через Karma
- Поддержка end-to-end тестирования — требуется установить дополнительный пакет

## Требования

- Node.js (рекомендуется LTS-версия)
- npm — устанавливается вместе с Node.js
- Angular CLI 15.0.0

Angular CLI можно установить глобально:

```bash
npm install -g @angular/cli
```

## Установка

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/DanWahlin/Angular-HelloWorld.git
   cd Angular-HelloWorld
   ```

2. Установите зависимости:

   ```bash
   npm install
   ```

3. Запустите сервер разработки:

   ```bash
   ng serve
   ```

   Если в `package.json` определён скрипт `start`, можно использовать:

   ```bash
   npm start
   ```

## Пример использования

После запуска `ng serve` откройте браузер по адресу:

```text
http://localhost:4200/
```

Приложение автоматически перезагрузится, если вы измените исходные файлы.

Сгенерировать новый компонент:

```bash
ng generate component component-name
```

Доступны и другие схемы:

```bash
ng generate directive|pipe|service|class|guard|interface|enum|module
```

Собрать проект:

```bash
ng build
```

Результат сборки будет сохранён в папке `dist/`.

Запустить юнит-тесты:

```bash
ng test
```

Запустить end-to-end тесты:

```bash
ng e2e
```

Для использования `ng e2e` необходимо сначала добавить пакет, реализующий возможности e2e-тестирования.
