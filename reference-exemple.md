## О проекте

`AngularHelloWorld` — учебный проект на Angular, сгенерированный через Angular CLI
версии `15.0.0`.

Основные сведения:

| Параметр | Значение |
|----------|----------|
| Название | AngularHelloWorld |
| Тип | Angular-приложение |
| Генератор | Angular CLI 15.0.0 |
| Dev-сервер | `http://localhost:4200/` |
| Сборка | каталог `dist/` |
| Unit-тесты | Karma |
| E2E-тесты | требуют добавления пакета для e2e-тестирования |

## Требования

Для работы с проектом нужны:

- Node.js и npm;
- Angular CLI;
- зависимости проекта, устанавливаемые через npm.

Точные версии Node.js и npm в README проекта не указаны.

## Команды

Общий вид вызова Angular CLI:

```bash
ng <команда> [параметры]
```

### serve

Запускает dev-сервер.

| Поле | Значение |
|------|----------|
| Команда | `ng serve` |
| Результат | Приложение доступно по адресу `http://localhost:4200/` |
| Особенность | При изменении исходных файлов приложение автоматически перезагружается |
| Пример | `ng serve` |

### generate

Генерирует элемент Angular-приложения.

| Поле | Значение |
|------|----------|
| Команда | `ng generate <тип> <имя>` |
| Поддерживаемые типы | `component`, `directive`, `pipe`, `service`, `class`, `guard`, `interface`, `enum`, `module` |
| Пример компонента | `ng generate component component-name` |
| Пример сервиса | `ng generate service my-service` |

### build

Собирает проект.

| Поле | Значение |
|------|----------|
| Команда | `ng build` |
| Результат | Артефакты сборки сохраняются в каталог `dist/` |
| Пример | `ng build` |

### test

Запускает unit-тесты через Karma.

| Поле | Значение |
|------|----------|
| Команда | `ng test` |
| Тестовый раннер | Karma |
| Пример | `ng test` |

### e2e

Запускает end-to-end тесты.

| Поле | Значение |
|------|----------|
| Команда | `ng e2e` |
| Условие | Нужно предварительно добавить пакет, реализующий e2e-тестирование |
| Пример | `ng e2e` |

### help

Выводит справку по Angular CLI.

| Поле | Значение |
|------|----------|
| Команда | `ng help` |
| Альтернатива | Официальная документация Angular CLI |
| Пример | `ng help` |

## Как собрать весь код в один Markdown

Чтобы действительно получить весь код проекта в одном Markdown-файле, нужно
клонировать репозиторий и выполнить сборку файлов локально.

```bash
git clone https://github.com/DanWahlin/Angular-HelloWorld.git
cd Angular-HelloWorld
```

Пример безопасного скрипта, который собирает текстовые файлы проекта в `ALL_CODE.md`,
исключая `.git/` и `node_modules/`:

```bash
find . \
  -path ./.git -prune -o \
  -path ./node_modules -prune -o \
  -type f -print | sort | while read -r f; do
    printf '\n## %s\n\n```\n' "$f"
    cat "$f"
    printf '\n```\n'
done > ALL_CODE.md
```

После выполнения в корне проекта появится `ALL_CODE.md` со всеми текстовыми
файлами репозитория.
