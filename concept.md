# Концепция проекта Angular-HelloWorld

## Что это

Angular-HelloWorld — это учебный проект на Angular, сгенерированный с помощью Angular CLI версии 15.0.0.
Проще говоря: минимальное приложение, которое можно запустить, чтобы увидеть работу фреймворка Angular
и познакомиться со стандартной структурой проекта.

Проект не содержит сложной бизнес-логики. Его задача — показать, как выглядит типичный Angular-проект
«из коробки»: стартовый компонент, маршрутизация (отсутствует или минимальна), конфигурация сборки
и тестирования. Весь исходный код находится в каталоге `src/`, а настройки — в корневых файлах
(`angular.json`, `tsconfig.json`, `package.json` и др.).

## Зачем нужно

Angular CLI генерирует проект для быстрого старта. Такой hello-world полезен:

- новичкам — чтобы увидеть, как выглядит Angular-приложение и как его запустить;
- преподавателям — как основа для демонстрации возможностей фреймворка;
- разработчикам — как шаблон для создания новых проектов (через `ng new`).

Без такого шаблона пришлось бы вручную настраивать сборку, TypeScript, тестовое окружение и структуру
каталогов. Angular CLI делает это автоматически, а проект служит наглядным результатом генерации.

## Как устроено

Проект следует стандартному соглашению Angular CLI:

- `src/` — исходный код приложения:
  - `app/` — корневой модуль и компоненты (в hello-world обычно один компонент `AppComponent`);
  - `assets/` — статические ресурсы;
  - `index.html` — главная HTML-страница;
  - `main.ts` — точка входа, загружающая корневой модуль;
  - `styles.css` — глобальные стили.
- `angular.json` — конфигурация сборки (бюджеты, пути, цели).
- `package.json` — зависимости и скрипты (`ng serve`, `ng build`, `ng test`, `ng e2e`).
- `tsconfig*.json` — настройки TypeScript.
- `.vscode/`, `.editorconfig`, `.gitignore` — вспомогательные файлы для разработки.

Сам проект не хранит данные и не имеет серверной части. Это чисто клиентское приложение, которое
при запуске отображает приветственную страницу Angular. Номера версий и зависимости фиксируются
в `package-lock.json`, что обеспечивает воспроизводимость сборки.

## Как связано с остальным

Angular-HelloWorld — это основа для всех последующих доработок. От него зависят:

- **команда `ng serve`** — запускает dev-сервер на `http://localhost:4200/` с автоматической
  перезагрузкой при изменении файлов;
- **команда `ng build`** — собирает проект в каталог `dist/` для продакшена;
- **команда `ng test`** — запускает юнит-тесты через Karma;
- **команда `ng e2e`** — запускает end-to-end тесты (требует дополнительного пакета);
- **генерация кода** — через `ng generate` можно добавлять компоненты, директивы, сервисы и т.д.,
  расширяя проект.

Проект не связан с настройками окружения: конфигурация Angular CLI уже включает всё необходимое
для разработки и сборки. Дальнейшие изменения (добавление маршрутов, сервисов, модулей) выполняются
поверх этой базовой структуры.
