## 1. Что за проект

`Angular-HelloWorld` — учебный проект-заготовка, созданный с помощью Angular CLI (версия 15.0.0). Это минимальное приложение «Hello World» на Angular, которое демонстрирует базовую структуру проекта и стандартные команды CLI для разработки, сборки и тестирования. Проект не содержит сложной бизнес-логики; его основная ценность — в демонстрации того, как выглядит и запускается типичное Angular-приложение.

Проект небольшой по объёму, последние изменения в `src/index.html` датированы ноябрём 2022 года, остальные файлы не менялись с момента первого коммита.

## 2. Кто им пользуется

| Группа | Что ей нужно от документации |
|---|---|
| Начинающий Angular-разработчик | Как установить зависимости, запустить сервер разработки и увидеть приложение в браузере |
| Разработчик, знакомый с Angular | Как устроена структура проекта, где находятся ключевые файлы (`main.ts`, `app`-компонент) и как использовать CLI для генерации кода |
| Преподаватель / проверяющий | Как быстро развернуть проект локально, какие команды выполнить для сборки и тестов, есть ли дополнительные требования |

Основная аудитория — **начинающие разработчики**, которые впервые сталкиваются с Angular и хотят понять, как запустить и модифицировать стандартное приложение, сгенерированное CLI.

## 3. Что уже есть

- [`README.md`](https://github.com/DanWahlin/Angular-HelloWorld/blob/main/README.md) — содержит базовые инструкции: `ng serve` для dev-сервера, `ng build` для сборки, `ng test` для юнит-тестов, `ng e2e` для end-to-end тестов, а также ссылку на официальную документацию Angular CLI.
- [`package.json`](https://github.com/DanWahlin/Angular-HelloWorld/blob/main/package.json) — определяет зависимости и скрипты, но не документирует их назначение отдельно.
- [`angular.json`](https://github.com/DanWahlin/Angular-HelloWorld/blob/main/angular.json) — конфигурация CLI; документации по ней в репозитории нет.
- Исходный код в `src/` — минимальный набор файлов (`index.html`, `main.ts`, `styles.css`, папка `app`), но **комментариев в коде практически нет**, за исключением стандартных строк, сгенерированных CLI.
- Папка `docs/` отсутствует. Отдельных руководств, FAQ или описания архитектуры нет.

## 4. Чего не хватает

Вопросы, на которые я не нашёл ответа при изучении проекта:

1. **Где находится «точка входа» приложения и как оно устроено.** В README перечислены команды CLI, но не объяснено, что приложение стартует из `src/main.ts`, что корневой компонент объявлен в `src/app/` и как эти файлы связаны. Без чтения кода это неочевидно.
2. **Как установить зависимости перед первым запуском.** В README сразу указано `ng serve`, но не упомянуто, что предварительно нужно выполнить `npm install`. Для новичка это может стать препятствием.
3. **Полное описание структуры проекта.** В репозитории есть папки `.vscode`, `src`, файлы конфигурации, но нет документа, который объяснял бы назначение каждой папки и каждого файла (например, зачем нужны `angular.json`, `.editorconfig`, `package-lock.json`).
4. **Как использовать CLI для генерации компонентов, сервисов и других артефактов.** README приводит общую команду `ng generate`, но не показывает конкретных примеров и не объясняет, какие флаги доступны и как они влияют на структуру проекта.
5. **Требования к окружению.** Не указана минимальная версия Node.js и npm, необходимые для работы Angular CLI 15.0.0. Это может вызвать ошибки при запуске на старых версиях.
6. **Лицензия.** В отличие от многих открытых проектов, в репозитории отсутствует файл `LICENSE`, поэтому неясно, на каких условиях можно использовать код.
