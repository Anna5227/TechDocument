# Первый запуск Angular HelloWorld

*Для новичков, займёт минут 10.*

Если вы только начинаете знакомство с Angular и хотите запустить готовый проект, этот гайд для вас. Мы склонируем репозиторий [Angular-HelloWorld](https://github.com/DanWahlin/Angular-HelloWorld), установим зависимости, запустим dev-сервер и даже изменим приветствие. В конце вы соберёте проект и запустите тесты.

За 10 минут вы пройдёте путь от клонирования до работающего приложения в браузере. Это стандартный рабочий процесс Angular-разработчика, на котором держится вся дальнейшая работа.

## Что понадобится

- Node.js версии 18.13+ (или 20+). Проверьте командой `node --version`
- npm (устанавливается вместе с Node.js)
- Git для клонирования репозитория
- Минут 10 свободного времени

> Совет: если у вас ещё не установлен Angular CLI глобально, не страшно — в проекте он уже есть локально, и мы будем использовать `npx`.

## Шаг 1. Клонируйте репозиторий и установите зависимости

1. Откройте терминал и перейдите в папку, где будет жить проект.
2. Выполните команду:
   ```bash
   git clone https://github.com/DanWahlin/Angular-HelloWorld.git
   ```
3. Перейдите в папку проекта:
   ```bash
   cd Angular-HelloWorld
   ```
4. Установите зависимости:
   ```bash
   npm install
   ```

> **Вы должны увидеть:** в терминале появится папка `node_modules`, а в выводе `npm install` не будет критических ошибок.

<details>
<summary>Зачем нужен npm install</summary>

В файле `package.json` перечислены все библиотеки, которые использует проект, включая Angular и инструменты сборки. Команда `npm install` скачивает их в папку `node_modules`. Без этого шага проект не запустится.

</details>

## Шаг 2. Запустите dev-сервер

1. Находясь в папке проекта, выполните:
   ```bash
   npm start
   ```
   (или `npx ng serve`, если скрипта `start` нет)
2. Дождитесь, пока в терминале появится сообщение о компиляции.
3. Откройте браузер и перейдите по адресу `http://localhost:4200/`.

> **Вы должны увидеть:** страницу с приветствием Angular. В терминале написано, что приложение успешно скомпилировано.

> **Важно:** не закрывайте терминал, пока работаете с приложением. Dev-сервер следит за изменениями и автоматически перезагружает страницу.

## Шаг 3. Измените приветствие

1. Откройте файл `src/app/app.component.html` в любом редакторе (например, VS Code).
2. Найдите текст приветствия и замените его на свой, например:
   ```html
   <h1>Привет, Angular!</h1>
   ```
3. Сохраните файл.

> **Вы должны увидеть:** страница в браузере обновится автоматически, и вы увидите новый заголовок. Если этого не произошло, проверьте, что dev-сервер всё ещё работает.

<details>
<summary>Почему изменения видны сразу</summary>

Angular CLI запускает dev-сервер с «горячей перезагрузкой» (hot reload). Он отслеживает изменения файлов и пересобирает приложение на лету. Вам не нужно вручную перезапускать сервер.

</details>

## Шаг 4. Соберите проект

1. Остановите dev-сервер, нажав `Ctrl+C` в терминале.
2. Выполните команду:
   ```bash
   npm run build
   ```
   (или `npx ng build`)
3. Дождитесь окончания сборки.

> **Вы должны увидеть:** в папке проекта появится директория `dist/` с готовыми файлами для публикации. В терминале будет сообщение об успешной сборке.

## Шаг 5. Запустите тесты

1. Выполните команду:
   ```bash
   npm test
   ```
   (или `npx ng test`)
2. Откроется браузер (или тестовый раннер) с результатами тестов.

> **Вы должны увидеть:** сообщение о том, что все тесты прошли (или список выполненных тестов). Если тесты не запустились, проверьте, что вы находитесь в корне проекта.
